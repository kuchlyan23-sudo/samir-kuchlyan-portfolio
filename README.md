# Samir Kuchlyan - Personal Portfolio Website

A multi-page portfolio website adhering strictly to modern semantic HTML5 standards and WCAG 2.1 accessibility guidelines. Built to achieve a 100/100 score on Google Lighthouse Accessibility and SEO audits.

## Project Structure
- `index.html` - Home page with semantic landmarks, About section, Education, and Skills.
- `projects.html` - Projects gallery utilizing semantic `<article>`, `<header>`, and `<footer>` elements.
- `contact.html` - Tab-navigable accessible form with full `aria-*` tags and labels.
- `styles.css` - WCAG AAA/AA compliant styling with high contrast ratios and clear keyboard focus rings.

## Technologies Used
- HTML5 (Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
- CSS3 (Flexbox, Grid, Accessible Focus States)
- ARIA landmarks and accessible descriptions
- Target Audits: Lighthouse 100 Accessibility & SEO
